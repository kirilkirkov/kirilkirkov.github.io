💡 Note: in PHP-FPM a worker stays BUSY for the entire request — including DB / network waits. Watch Worker #2 while it runs the slow /report request: it stays occupied the whole time. This is different from Node.js's non-blocking event loop, where one process can juggle many waiting requests at once.

THE ONE THING TO REMEMBER

Nginx can handle many connections
PHP requests go to PHP‑FPM
PHP‑FPM has a limited worker pool
1 request occupies 1 PHP worker
available workers determine PHP concurrency
if all workers are busy…
…new PHP requests wait in the queue
when a worker finishes
it becomes FREE and handles the next request
